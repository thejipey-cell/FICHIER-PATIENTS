Configuration Firebase
Configurer la synchronisation
Suivez ces 4 étapes pour créer votre base de données gratuite. Cela prend environ 5 minutes.
1Allez sur console.firebase.google.com et créez un projet (bouton + Ajouter un projet). Désactivez Google Analytics si proposé.
2Dans votre projet, cliquez sur Firestore Database → Créer une base de données → choisissez Mode production → sélectionnez une région Europe.
3Allez dans Authentication → Commencer → activez le fournisseur E-mail/Mot de passe.
4Allez dans Règles de Firestore et remplacez le contenu par ces règles de sécurité :
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /patients/{id} { allow read, write: if request.auth != null && request.auth.uid == resource.data.userId; allow create: if request.auth != null && request.resource.data.userId == request.auth.uid; } } }
